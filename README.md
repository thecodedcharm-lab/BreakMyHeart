# 💗 Break My Heart 🔨

A tiny interactive website where you can break a heart with a hammer and put it back together again.

Made with HTML, CSS, and JavaScript, this project combines soft pink aesthetics with playful animations to create a simple, interactive experience.

## ✨ Features

* 💗 **Animated Heart**: A heart that gently beats using CSS animations.
* 🔨 **Break the Heart**: Click the hammer to break the heart into two pieces.
* 💔 **Breaking Animation**: Watch the two halves fall apart and fade away.
* 💬 **Interactive Messages**: The message changes when the heart breaks.
* 🔄 **Reset Button**: Put the heart back together and start again.
* 🎀 **Soft Pink Aesthetic**: A pastel color palette with a minimal design.
* 📱 **Responsive Design**: Includes styling adjustments for smaller screens.
* ♿ **Reduced Motion Support**: Respects the user's reduced-motion preference.

## 🛠️ Built With

* **HTML5**: Website structure
* **CSS3**: Styling, keyframe animations, transitions, and responsive design
* **JavaScript**: Click events, DOM manipulation, and interactive behavior
* **SVG**: Custom heart illustrations and clipping paths

## 🎮 How to Use

1. Open the website in your browser.
2. Watch the heart beat.
3. Click the 🔨 hammer to break it.
4. Read the message that appears.
5. Click **Put it back together** to reset the heart.
6. Repeat as many times as you like!
